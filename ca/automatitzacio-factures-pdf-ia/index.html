Factures i PDFs llegits per IA.
Del document al teu sistema, amb revisió quan cal.

Cada factura, albarà o formulari que arriba en PDF acaba amb algú teclejant els mateixos camps a l'ERP. Un sistema amb IA llegeix el document, extreu les dades —número, data, base, total, proveïdor, NIF—, les valida segons les teves regles i dona d'alta els casos d'alta confiança. Les excepcions queden pendents de revisió humana.

01 — Què fa

Teclejar el que ja està escrit / en un PDF és la feina / que primer desapareix.

Copiar un número de factura a l'ERP no requereix criteri: només consumeix temps i pot provocar errors de transcripció. És el primer candidat a automatitzar. El recorregut complet, del document al sistema:

// pdf_01 Llegeix

El document.

Factura, albarà, formulari o tiquet, tant si arriba per correu com per carpeta o escaneig. Admet múltiples formats de proveïdor, amb validació prèvia, sense dependre d'una única plantilla fixa.

// pdf_02 Extreu

Els camps.

Número, data, base, IVA, total, proveïdor, NIF, línies de detall. Treu el que necessitis de cada tipus de document, no només quatre caselles fixes.

// pdf_03 Valida

Contra les teves regles.

Comprova que el total quadra, que el proveïdor existeix, que el NIF té forma vàlida. Si alguna cosa no encaixa, ho marca en comptes de donar-ho d'alta a cegues.

// pdf_04 Registra

Al teu sistema.

Dona d'alta les dades al teu ERP, la teva comptabilitat o el teu full de càlcul. El document queda arxivat i enllaçat al seu registre. Sense copiar i enganxar.

02 — Amb control

Una dada mal posada a comptabilitat / costa més / que teclejar-la bé.

Automatitzar l'entrada de dades només compensa si et pots fiar del resultat. Per això els documents que compleixen les regles es donen d'alta i els casos dubtosos s'aturen perquè una persona els revisi. És el mateix principi de les tres preguntes abans d'implantar IA agèntica.

// ctrl_01 A revisió

Els casos dubtosos, aturats.

Si un camp no quadra, falta o el document és rar, no es dona d'alta: queda en una cua de revisió amb el problema assenyalat. Millor parar que embrutar el sistema.

// ctrl_02 Quadra

Els números quadren.

Comprova que bases, impostos, retencions i total quadren segons les regles aplicables; també contrasta els imports amb la comanda i detecta possibles duplicats.

// ctrl_03 Traçable

Cada dada, al seu origen.

Cada registre enllaça amb el document d'origen i indica quines dades se n'han extret. Si cal comprovar alguna cosa, el PDF original és a un clic: traçabilitat del document al registre.

03 — Cas real a Aimtech

De Gmail a Drive / amb 23 factures noves d'alta confiança arxivades a Drive / durant el tancament del 2T de 2026.

Aimtech utilitza aquest enfocament en la seva pròpia administració: detecta factures de proveïdor al correu i als portals, llegeix la data i l'identificador reals, evita duplicats i aplica una nomenclatura estable. Només els documents que compleixen les regles operatives predefinides per a l'alta automàtica poden passar a FacturaScripts, sempre amb les excepcions subjectes a revisió; el recompte de 23 no equival a 23 altes en aquest sistema. 04 — Contractació

Per a empreses, entitats i AAPP.

El pressupost es calcula segons l'abast després d'un diagnòstic curt: tipus de document, volum i integració amb el teu ERP o comptabilitat. Projectes des de 2.500€; l'abast defineix el pressupost final. Forma part de l'automatització de processos amb IA; si el teu cas se centra sobretot en el correu d'entrada, mira l'automatització de correus amb IA.
